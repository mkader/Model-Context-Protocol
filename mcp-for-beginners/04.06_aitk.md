### Consuming a server from the Foundry Tookkit extension for VSC

* It was before called "AI Toolkit (aitk)".
* When you’re building an AI agent, it’s not just about generating smart responses; it’s also about giving your agent the ability to take action.
* MCP makes it easy for agents to access external tools and services in a consistent way.

* connect an agent to calculator MCP server. Suddenly, your agent can perform math operations just by receiving a prompt like “What’s 47 times 89?”—no need to hardcode logic or build custom APIs.

#### Overview
* Connect a calculator MCP server to an agent with the [AI Toolkit](https://aka.ms/AIToolkit) extension in VSC, enabling your agent to perform math operations such as addition, subtraction, multiplication, and division through natural language.

* AI Toolkit is a powerful extension for VSC that streamlines agent development.
    * AI Engineers can easily build AI applications by developing and testing generative AI models—locally or in the cloud.
    * The extension supports most major generative models available today.
    * *Note*: The AI Toolkit currently supports Python and TypeScript.

#### Approach

Here's how we need to approach this at a high level:

- Create an agent and define its system prompt.
- Create a MCP server with calculator tools.
- Connect the Agent Builder to the MCP server.
- Test the agent's tool invocation via natural language.

5. Create a MCP server
     <img width="350" height="150" alt="image" src="https://github.com/user-attachments/assets/46157ec9-9f14-4523-a477-d17f24467a26" />
     
     * AI Toolkit is equipped with templates for ease of creating your own MCP server.
     * use the Python template for creating the calculator MCP server.
     * *Note*: The AI Toolkit currently supports Python and TypeScript.
     * Tools -> + MCP Server -> + Add Server -> Create a New MCP Server -> python-weather as the template -> Default folder to save the MCP server template -> server name - Calculator
         ```
         # create a virtual environment:
         python -m venv .venv
     
         # ativate the virtual environment:
         1. Windows - `.venv\Scripts\activate`
         1. macOS/Linux - `source .venv/bin/activate`
     
         # install the dependencies: `pip install -e .[dev]`
         ```
       * Expand the **src** directory and select **server.py** to open the file in the editor, replace the code and save
         ```python
         from mcp.server.fastmcp import FastMCP
         
         server = FastMCP("calculator")
         
         @server.tool()
         def add(a: float, b: float) -> float:
             """Add two numbers together and return the result."""
             return a + b
         
         @server.tool()
         def subtract(a: float, b: float) -> float:
             """Subtract b from a and return the result."""
             return a - b
         
         @server.tool()
         def multiply(a: float, b: float) -> float:
             """Multiply two numbers together and return the result."""
             return a * b
         
         @server.tool()
         def divide(a: float, b: float) -> float:
             """
             Divide a by b and return the result.
             
             Raises:
                 ValueError: If b is zero
             """
             if b == 0:
                 raise ValueError("Cannot divide by zero")
             return a / b
         ```

6. Run the agent with the calculator MCP server
     <img width="900" height="450" alt="image" src="https://github.com/user-attachments/assets/a8e762b2-1ed1-4cd2-b2ad-2a5885115f6d" />
     * Run the calculator MCP server on your local dev machine via the **Agent Builder** as the MCP client.
     * Press `F5` to start debugging the MCP server. The **Agent (Prompt) Builder** will open in a new editor tab. The status of the server is visible in the terminal.
     * In the **User prompt** field of the **Agent (Prompt) Builder**, enter the following prompt: `I bought 3 items priced at $25 each, and then used a $20 discount. How much did I pay?`
     * Click the **Run** button to generate the agent's response.
     * Review the agent output. The model should conclude that you paid **$55**.
     * Here's a breakdown of what should occur:
         - The agent selects the **multiply** and **substract** tools to aid in the calculation.
         - The respective `a` and `b` values are assigned for the **multiply** tool.
         - The respective `a` and `b` values are assigned for the **subtract** tool.
         - The response from each tool is provided in the respective **Tool Response**.
         - The final output from the model is provided in the final **Model Response**.
