### MCP-powered Voice Agent 
* build an MCP-driven voice Agent that queries a database and falls back to web search if needed.

  <img width="667" height="431" alt="image" src="https://github.com/user-attachments/assets/cbdd6ab7-4805-49d9-8e35-899089eb44aa" />

* Tech Stack 
  - AssemblyAI for Speech‐to‐Text. 
  - Firecrawl for web search. 
  - Supabase for a database. 
  - Livekit for orchestration. 
  - Qwen3 as the LLM. 
* Workflow: 
    - User's speech query is transcribed to text with AssemblyAI.
    - Agent discovers DB & web tools.
    - LLM invokes the right tool, fetches data & generates a response.
    - The app delivers the response via text-to-speech. 

1. Initialize Firecrawl & Supabase - instantiate Firecrawl to enable web searches and start our MCP server to expose Supabase tools to our Agent.

     <img width="681" height="350" alt="image" src="https://github.com/user-attachments/assets/d278991e-4f52-43c8-9fda-18e254444568" />

2. Define web search tool  - fetch live web search results using Firecrawl search endpoint. This gives our agent up-to-date online information.

     <img width="641" height="463" alt="image" src="https://github.com/user-attachments/assets/0d48e9c7-cd90-4e76-886b-535d54c87f38" />

3. Get Supabase MCP Tools - list our Supabase tools via the MCP server and wrap each of them as LiveKit tools for our Agent.

     <img width="561" height="485" alt="image" src="https://github.com/user-attachments/assets/8b7cc3aa-f050-4c94-a001-5f8b608b7435" />

4. Build the Agent - set up our Agent with instructions on how to handle user queries. We also give it access to the Firecrawl web search and Supabase tools defined earlier.

   <img width="572" height="346" alt="image" src="https://github.com/user-attachments/assets/e2b798f7-a9e9-40b8-84bd-2ed4890a2220" />

5. Configure Speech-to-Response flow
    - transcribe user speech with AssemblyAI Speech-to-Text.
    - Qwen 3 LLM, served locally with Ollama, invokes the right tool.
    - A voice output is generated via TTS.

      <img width="492" height="442" alt="image" src="https://github.com/user-attachments/assets/aff301ea-a8a0-4c7c-8729-fd76e75accdf" />

6. Launch the Agent - connect to LiveKit and start our session with a greeting. Then continuously listen and respond until the user stops.

   <img width="373" height="357" alt="image" src="https://github.com/user-attachments/assets/7a04b070-add2-499e-a856-8af6e95bf918" />
   
7. Our MCP-powered Voice Agent is ready. 
    - If the query is related to a database, it queries Supabase via MCP tools. 
    - Otherwise, it performs a web search via Firecrawl.
