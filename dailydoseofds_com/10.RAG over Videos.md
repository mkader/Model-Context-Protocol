## Build an MCP-powered RAG over Videos

* MCP-driven video RAG that ingests a video and lets you chat with it. It also fetches the exact video chunk where an event occurred.
  
* Chat with videos and get precise timestamps.

    <img width="805" height="522" alt="image" src="https://github.com/user-attachments/assets/1492a687-6303-47a1-b569-66abcefe43c9" />


* Our tech stack:
    - ​[Ragie](https://ragie.ai/)​ for video ingestion and retrieval.
    - Cursor as the MCP host.

* Here's the workflow:
    - User specifies video files and a query.
    - An Ingestion tool indexes the videos in Ragie.
    - A Query tool retrieves info from Ragie Index with citations.
    - A show-video tool returns the video chunk that answers the query.

1. Ingest data - ingest video files into the Ragie index.
    - Specify the audio-video mode to load both audio and video channels during ingestion.
      
  <img width="690" height="652" alt="image" src="https://github.com/user-attachments/assets/245f103f-1cae-4783-aa4b-5f6ca9faed30" />

3. Retrieve data - retrieve the relevant chunks from the video based on the user query. 
    - Each chunk has a start time, an end time, and a few more details that correspond to the video segment.

    <img width="682" height="453" alt="image" src="https://github.com/user-attachments/assets/7b6fa0bd-3b8b-496f-9c3d-4f6296e0ad2c" />

4. Create MCP Server - integrate our RAG pipeline into an MCP server with 3 tools:
    - ingest_data_tool: Ingests data into Ragie index.
    - retrieve_data_tool: Retrieves data based on the user query.
    - show_video_tool: Creates video chunks from the original video.

    <img width="715" height="625" alt="image" src="https://github.com/user-attachments/assets/a9b0444b-dc10-4c3f-ac2f-514607f69f82" />
