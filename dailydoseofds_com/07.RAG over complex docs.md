## RAG over complex docs.md
* used MCP to power an RAG application over complex documents with tables, charts, images, complex layouts, and whatnot.
*  here’s our document
    <img width="1000" height="372" alt="image" src="https://github.com/user-attachments/assets/7cb042c7-2335-46c6-91af-85ce111df746" />

* tech Stack:
    - Cursor IDE as the MCP client.
​    - [EyelevelAI's GroundX](https://www.eyelevel.ai)​ to build an MCP server that can process complex docs.

* Here's how it works:
    - User interacts with the MCP client (Cursor IDE)
    - Client connects to the MCP server and selects a tool.
    - Tools leverage GroundX to do an advanced search over docs.
    - Search results are used by the client to generate responses.
      
    <img width="698" height="533" alt="image" src="https://github.com/user-attachments/assets/5a3678c4-786e-40ac-8c70-5a2def763195" />
