### MCP Projects - 100% local MCP Client
* An MCP client is a component in an AI app (like Cursor) that establishes connections to external tools.
* Learn how to build it 100% locally.

    <img width="650" height="500" alt="image" src="https://github.com/user-attachments/assets/6342f5a8-ba62-483c-bcb0-482fc98075c0" />

#### Tech stack: 
* Llamaindex to build the MCP-powered Agent 
* Ollama to locally serve Deepseek-R1. 
* LightningAI for development and hosting 

#### Workflow: 
* User submits a query.
* Agent connects to the MCP server to discover tools.
* Based on the query, agent invokes the right tool and get context
* Agent returns a context-aware response. 

#### Let’s implement this! 
1. Build an SQLite MCP Server - with two tools: 1) add data and 2) fetch data

  - It's s simple, but the client we're building can connect to any MCP server out there. 

2. Set Up LLM - use a locally served Deepseek-R1 via Ollama as the LLM for our MCP-powered agent.

    <img width="775" height="171" alt="image" src="https://github.com/user-attachments/assets/4d88af3b-bc69-49ed-975a-d730702d20e8" />

3. Define system prompt  - define our agent’s guiding instructions to use tools before answering user queries.

    <img width="632" height="216" alt="image" src="https://github.com/user-attachments/assets/9dc1f54e-15b9-4f79-9fac-cd3f2c3d68d2" />

4. Define the Agent - define a function that builds a typical LlamaIndex agent with its appropriate arguments. 
    - The tools passed to the agent are MCP tools, which llama_index wraps as native tools that can be easily used by our FunctionAgent.
  
    <img width="680" height="381" alt="image" src="https://github.com/user-attachments/assets/604f0a4a-f664-4a92-a52f-be15ee3b2808" />

5. Define Agent Interaction -
    - pass user messages to our FunctionAgent with a shared Context for memory, stream tool calls and return its reply.
    - We manage all the chat history and tool calls here.

    <img width="680" height="555" alt="image" src="https://github.com/user-attachments/assets/21bce942-7233-4e20-8914-6fd75b8ce931" />
  
6. Initialize MCP Client and the Agent
    - Launch the MCP client, load its tools, and wrap them as native tools for function-calling agents in LlamaIndex.
    - Then, pass these tools to the agents and add the context manager. 
  
    <img width="680" height="381" alt="image" src="https://github.com/user-attachments/assets/1ecffa95-7ea9-4b4d-b0b8-fa29ed00d91b" />

7. Run the Agent - Finally, we start interacting with our agent and get access to the tools from our SQLite MCP server.

   <img width="680" height="502" alt="image" src="https://github.com/user-attachments/assets/67a5f30d-6d12-49f2-a2b7-8839d2dfbc62" />
    
    - When we say something like "Add Rafael Nadal...," the agent understands the intent, generates a corresponding SQL INSERT command, and stores the data in the database.
    - When we say "fetch data," it runs a SELECT query and retrieves the data. It then presents the result back to the user in a readable format.
