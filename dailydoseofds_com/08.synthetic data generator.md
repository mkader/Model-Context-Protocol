* building an MCP server that every data scientist will love to have.
* It’s an MCP server that can generate any type of synthetic dataset.
* Synthetic dataset is important because it gives us more data from existing samples, especially when real-world data is limited, imbalanced, or sensitive.

* Here’s our tech stack:
    - Cursor as the MCP host.
    ​- [Datacebo's SDV](https://docs.sdv.dev/sdv)​ to generate realistic tabular synthetic data.

* SDV is a Python library​ that uses ML to create synthetic data resembling real-world patterns. The process involves training a model, sampling data, and validating against the original.

    <img width="947" height="447" alt="image" src="https://github.com/user-attachments/assets/6d010bb2-1965-431e-bd1f-3ec44f55a7cb" />

* system overview
    - User submits a query
    - Agent connects to the MCP server to find tools
    - Agent uses the appropriate tool based on the query
    - Returns response on synthetic data creation, eval, or visualization

    <img width="712" height="531" alt="image" src="https://github.com/user-attachments/assets/ae28f3f7-8ad5-4c66-895a-afa6d036db63" />

* Our MCP server will have three tools:

1. Tool 1) SDV Generate Tool - creates synthetic data from real data using the SDV Synthesizer.
    - SDV offers a variety of synthesizers, each utilizing different algorithms to produce synthetic data.
    
    <img width="787" height="671" alt="image" src="https://github.com/user-attachments/assets/b40c508f-70d5-4a34-9134-3f5b55fe8a4d" />

2. Tool 2) SDV Evaluate Tool - evaluates the quality of synthetic data in comparison to real data.
    - We will assess statistical similarity to determine which real data patterns are captured by the synthetic data.

    <img width="632" height="745" alt="image" src="https://github.com/user-attachments/assets/1176ff1b-56b9-465c-aed4-0d6d5733f512" />


3. Tool 3) SDV Visualize Tool - generates a visualization to compare real and synthetic data for a specific column.
   - Use this function to visualize a real column alongside its corresponding synthetic column.
