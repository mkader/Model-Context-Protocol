* This project builds an MCP server to query and chat with over 200+ data sources using NL through a unified interface powered by MindsDB and Cursor IDE. 
  <img width="822" height="490" alt="image" src="https://github.com/user-attachments/assets/66097f28-d050-4de5-890f-f91271d01ce6" />

* Tech stack 
  - MindsDB to power our unified MCP server 
  - Cursor as the MCP host 
  - Docker to self-host the server 
* Workflow 
  - User submits a query 
  - Agent connects to the MindsDB MCP server to find tools 
  - Selects the appropriate tool based on the user query and calls it 
  - Finally, returns a contextually relevant response 

1. Install Docker MindsDB image locally.
  <img width="678" height="298" alt="image" src="https://github.com/user-attachments/assets/32599380-4528-4aac-9cf6-d7e7e72daae8" />

2. Start MindsDB GUI - Browser -> 127.0.0.1:47334 -> access the MindsDB editor. Can connect to over 200 data sources and run SQL queries against them. 
3. Integrate Data Sources - Building federated query engine by connecting our data sources to MindsDB. Slack, Gmail, GitHub and Hacker News as our federated data sources.
   <img width="402" height="388" alt="image" src="https://github.com/user-attachments/assets/be2f97a0-1a00-4f8f-9656-c1f52fb3a53f" />

4. Integrate MCP Server with Cursor - After building the federated query engine, unify our data sources by connecting them to MindsDB's MCP server. 
  * Go to: File → Preferences → Cursor Settings → MCP → Add new global MCP server. JSON file
  * Done! Our MindsDB MCP server is live and connected to Cursor! 
  <img width="521" height="453" alt="image" src="https://github.com/user-attachments/assets/a8b59e05-2eb8-4840-af7a-fa0f21c3174c" />

  * The MCP server offers two tools: 
    - list_databases: Lists all data sources connected to MindsDB. 
    - query: Answers user queries on the federated data.
