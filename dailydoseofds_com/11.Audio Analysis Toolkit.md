## Build an MCP-powered Audio Analysis Toolkit

* MCP-driven Audio Analysis toolkit that accepts an audio file and lets you:
    1. Transcribe it
    2. Perform sentiment analysis
    3. Summarize it
    4. Identify named entities mentioned
    5. Extract broad ideas 6. Interact with it

  <img width="703" height="502" alt="image" src="https://github.com/user-attachments/assets/9dffd149-b987-48a2-bd6c-27283a438477" />

* tech stack:
    - [​AssemblyAI](https://www.assemblyai.com/dailydose)​ for transcription and audio analysis.
    - Claude Desktop as the MCP host.
    - Streamlit for the UI

* Here's our workflow:
    - User's audio input is sent to AssemblyAI via a local MCP server.
    ​- AssemblyAI​ transcribes it while providing the summary, speaker labels, sentiment, and topics.
    - Post-transcription, the user can also chat with audio.

1. Transcription MCP tool - accepts an audio input from the user and transcribes it using AssemblyAI. We also store the full transcript to use in the next tool.

  <img width="486" height="438" alt="image" src="https://github.com/user-attachments/assets/f6ba0d5e-08a5-4e7b-ab8e-5c4709725a35" />

2. Audio analysis tool - returns specific insights from the transcript, like speaker labels, sentiment, topics, and summary. Based on the user’s input query, the corresponding flags will be automatically set to True when the Agent will prepare the tool call via MCP:
